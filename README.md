# Jogo do Número Secreto

Este projeto é um jogo de adivinhação desenvolvido com HTML, CSS e JavaScript.  
O objetivo é descobrir um número secreto entre 1 e 50, recebendo dicas sobre se o valor informado é maior ou menor que o número correto.

## Funcionalidades

- Interface simples e visualmente organizada
- Validação de entrada para números entre 1 e 50
- Feedback ao usuário após cada tentativa
- Botão para reiniciar o jogo
- Reprodução de áudio com a API ResponsiveVoice

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- ResponsiveVoice
- Google Fonts

## Estrutura do projeto

- `index.html`: estrutura da página principal
- `style.css`: estilos da interface
- `app.js`: lógica do jogo
- `img/`: imagens utilizadas no projeto

## Como executar

1. Faça o download ou clone este projeto em sua máquina.
2. Abra o arquivo `index.html` em um navegador.
3. Digite um número e clique em "Chutar" para começar a jogar.

## Observações

- Este projeto foi criado como exemplo de aplicação web com lógica em JavaScript.
- Para que os recursos de voz e fontes funcionem corretamente, é recomendável usar um navegador moderno com acesso à internet.
